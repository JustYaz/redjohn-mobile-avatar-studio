# Mobile Avatar Studio branding

These are the approved M.A.S. branding assets used by the package documentation and repository presentation.

- `mas-icon-1024.png` — square reusable icon for documentation, release pages, editor branding, and future icons.
- `github-social-preview-1280x640.png` — GitHub social-preview image for repository and link previews.
- `readme-banner-1800x600.png` — wide banner displayed at the top of the root README.
- `Source/` — untouched copies of the supplied source image exports.

M.A.S. means **Mobile Avatar Studio**. The approved brand colors are red, black/charcoal, silver-gray, and white.

The logo must not be recolored, distorted, stretched, rearranged, or otherwise redesigned. The final exports are only cropped, resized, and optimized for their documented uses.
