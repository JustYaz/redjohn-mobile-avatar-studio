# Security policy

Please do not publish private avatar packages, credentials, project archives, or private controller assets in a public issue.

For a security or privacy-sensitive report, contact the project maintainer privately before opening an issue. Include a minimal reproduction, Unity/SDK versions, the affected stage, and sanitized logs where possible.

Mobile Avatar Studio is an editor tool. It does not upload avatars by itself; Stage 8 invokes the installed VRChat SDK build path and records build measurements locally.
