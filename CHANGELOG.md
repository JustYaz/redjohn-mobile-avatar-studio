# Changelog

## 0.1.0 - Official first release

- First official release of M.A.S. Mobile Avatar Studio.
- Includes non-destructive mobile-avatar analysis, mesh candidates, UV-tile splitting, reviewed material and texture conversion, behavior remapping, component repair, and mobile validation.
- The original PC avatar remains protected while the mobile counterpart is built in an isolated workspace.
- Available as a VPM ZIP, VPM TGZ, and UnityPackage download from the release page.
